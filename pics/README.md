# 图片管理说明

目标是把每个页面用到的照片放在单独文件夹里，后续替换时只需要按页面找到对应目录。

## 建议目录

| 页面 / 模块 | 建议目录 | 需要照片 | 当前用途 |
| --- | --- | ---: | --- |
| 手势舞台照片球 | `pics/shoushi/` | 6 张 | 展开蛋糕后围绕照片球旋转，也会进入照片弹窗 |
| 开场照片墙 | `pics/kaichang/` | 3 张 | “生日序章”右侧照片墙 |

| 拍立得相册墙 | `pics/pailide/` | 4 张 | 四张拍立得照片和点击后的照片弹窗 |
| 祝福卡片 | `pics/zhufu/` | 1 张 | “抽取一张生日祝福”右侧背景照片 |
| 信件照片 | `pics/xinjian/` | 2 张 | 信件下方两张照片 |

## 命名建议

- 固定数量页面用 `01.jpg`、`02.jpg`、`03.jpg` 这种命名，替换时不需要改代码。
- 时间线也可以用 `2021.jpg`、`2022.jpg`、`2023.jpg`、`2026.jpg`，语义更清楚。
- 每张图建议宽度不低于 1200px，拍立得和头像类照片优先用竖图或正方形图。
- 当前页面直接加载 `pics/` 里的图片，不再需要运行照片加密脚本。

## 当前状态

当前页面代码仍引用 `pics/` 根目录下的图片。要完全变成“每页一个文件夹”，下一步需要把 `index.html` 和 `script.js` 里的照片路径改成上表目录。
